# Bundled demo data

This deterministic simulated dataset was generated with seed 20261115 for CommerceLab. It is shaped to the documented normalized GA4 export schema but is not a copy or extract of Google's public GA4 sample. It contains 5,757 events across 585 observed user IDs (sampled from a pool of 620 possible user IDs) and 2020-11-01 through 2021-01-31. Run the generator script to reproduce it.
